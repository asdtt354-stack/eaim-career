EAIM 진로

나를 알고, 변하는 직업 세계를 탐색하고, 나만의 길을 설계하는 진로 수업이에요. 감성·예술적 환경·상호작용·음악화가 살아 있는 활동으로 만나요. 활동은 누구나 연습할 수 있고, 선생님께 내기는 수업 QR로 들어왔을 때만 돼요.

👉 이렇게 시작해요카드를 누르면 활동이 열려요. 활동 안의 초록 상자 "👉 지금 할 일" 순서대로 누르고 쓰면 돼요. 💡 표시는 읽어 두는 설명이에요.

📲 홈 화면·바탕화면에 아이콘으로 두기

한 번 두면 아이콘을 눌러 바로 열려요.

  • 컴퓨터(크롬·엣지): 주소창 오른쪽의 설치 아이콘(⊕ 또는 ⬇)을 누르거나 위 설치하기 → 바탕화면에 아이콘이 생겨요
  • 안드로이드 크롬: ⋮ 메뉴 → 홈 화면에 추가
  • 삼성 인터넷: ≡ 메뉴 → 현재 페이지 추가 → 홈 화면 (주소창의 ⬇ 설치는 쓰지 않아요)
  • 아이폰·아이패드(사파리): 공유 버튼 → 홈 화면에 추가
